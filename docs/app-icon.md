# Іконка застосунку

Оригінали:

- macOS: `archive_flutter/assets/branding/app_icon.png`.
- Windows: `archive_flutter/assets/branding/app_icon_windows.png` — збільшений знак, мінімальні прозорі поля й тонка нейтральна обводка.

Конфігурація: `archive_flutter/flutter_launcher_icons.yaml`.

Щоб змінити іконку, замініть оригінал і виконайте в `archive_flutter`:

```sh
flutter pub get
dart run tool/generate_app_icons.dart
```

Збережіть у Git оригінал, конфігурацію та створені ресурси:

- Windows: `windows/runner/resources/app_icon.ico` із кадрами 16, 20, 24, 32, 40, 48, 64, 96, 128 і 256 px (використовується виконуваним файлом і установщиком Inno Setup).
- macOS: `macos/Runner/Assets.xcassets/AppIcon.appiconset/`.

Сценарій `tool/build_windows.ps1` автоматично запускає цей генератор перед збіркою. Прямий запуск `flutter_launcher_icons` створює лише один кадр Windows; використовуйте обгортку вище, щоб зберегти всі розміри. macOS використовує готові ресурси з репозиторію.

Після Windows-збірки `tool/test_windows_icon.ps1` використовує справжній Shell API `ExtractIconExW`: велика й мала іконки виконуваного файлу мають бути видимими та збігатися з оригінальним ICO. Якщо в EXE залишилася іконка Flutter або Windows не може її витягти, створення установщика припиняється. Ця перевірка виконується на Windows, зокрема у workflow випуску; на macOS її виконати неможливо.

Процес і ярлики мають спільний стабільний `AppUserModelID` — `Archive.Desktop`. Це пов'язує вікно з ярликом на панелі завдань. Inno Setup також встановлює копію ICO в `{app}\icons\archive-<build>.ico` і явно вказує її для ярликів та списку встановлених програм. Новий шлях у кожному випуску дозволяє Explorer отримати нову іконку замість кешованої іконки старого EXE. Попередні копії зберігаються до видалення застосунку, оскільки на них можуть посилатися закріплені ярлики. AppId установщика, ім'я EXE та каталоги даних не змінюються.

Щоб побачити зміну в Dock або у Windows, повністю перезберіть і перезапустіть застосунок. Hot reload і hot restart не оновлюють нативні іконки. Встановлені Windows-клієнти отримають зміни з наступним випуском установщика. Раніше закріплений на панелі завдань ярлик може зберегти стару іконку: після встановлення нового випуску відкріпіть його, запустіть «Archive» з меню «Пуск» і закріпіть знову. Автоматично видаляти користувацькі закріплення або системний кеш іконок не потрібно.
